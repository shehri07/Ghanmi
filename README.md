🐑 Ghanmi – نظام إدارة الأغنام

فكرة المشروع

غانمي هو نظام إلكتروني لإدارة وتنظيم شؤون الأغنام، يهدف إلى تسهيل متابعة القطيع وإدارة بياناته اليومية من خلال واجهة موحدة وسهلة الاستخدام.

جاءت فكرة المشروع لتوفير حل رقمي يساعد أصحاب الحلال والمربين على تنظيم أعمالهم، بدلًا من الاعتماد على التسجيل اليدوي أو تشتت المعلومات بين الدفاتر والملاحظات.

المشكلة التي يعالجها المشروع

يواجه مربو الأغنام عدة تحديات في إدارة حلالهم، منها:

- صعوبة متابعة أعداد الأغنام وتصنيفها.
- تشتت بيانات الأغنام وعدم سهولة الرجوع إليها.
- صعوبة متابعة المواليد والوفيات والمشتريات والمبيعات.
- عدم تنظيم السجلات الصحية والعلاجات والتحصينات.
- صعوبة معرفة المصروفات والإيرادات ومتابعة التكاليف.
- الحاجة إلى تقارير واضحة تساعد في متابعة وضع القطيع.

أهداف المشروع

1. تنظيم بيانات الأغنام في مكان واحد.
2. تسهيل متابعة القطيع وأعداده وتصنيفاته.
3. توثيق المواليد والوفيات والحركة اليومية.
4. تنظيم السجلات الصحية والبيطرية.
5. متابعة المشتريات والمبيعات.
6. إدارة المصروفات والإيرادات.
7. توفير إحصائيات وتقارير تساعد في اتخاذ القرارات.
8. تقليل الأخطاء الناتجة عن التسجيل اليدوي.

الوظائف الرئيسية للنظام

يتضمن النظام مجموعة من الأقسام لإدارة مختلف جوانب تربية الأغنام، ومنها:

- لوحة التحكم والإحصائيات.
- إدارة الأغنام وبياناتها.
- إدارة المواليد والتناسل.
- متابعة الصحة والعلاجات والتحصينات.
- إدارة التغذية.
- تسجيل المشتريات والمبيعات.
- إدارة المصروفات والإيرادات.
- التقارير والإحصائيات.
- الإعدادات وإدارة بيانات النظام.

الفئة المستهدفة

- أصحاب الحلال ومربو الأغنام.
- أصحاب المشاريع الصغيرة والمتوسطة في مجال تربية المواشي.
- المزارع ومشاريع الإنتاج الحيواني.

رؤية المشروع

أن يكون غانمي مساعدًا رقميًا متكاملًا للمربي، يجمع بيانات القطيع وعملياته اليومية في نظام واحد، ويساعد على تحسين التنظيم والمتابعة والإدارة.

التقنيات المستخدمة

تم تطوير الواجهة باستخدام:

- React
- TypeScript
- Vite
- CSS

حالة المشروع

المشروع في مرحلة تطوير الواجهة الأمامية (Frontend)، ويستخدم حاليًا بيانات تجريبية محلية.

سيتم تطوير وظائف النظام وربطها بخدمات خلفية وقاعدة بيانات في المراحل القادمة.
